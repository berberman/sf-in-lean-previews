431+-- Lean's language server can suggest *code actions*, which are small editor
432+-- commands that modify the source code. In VS Code, a lightbulb icon appears
433+-- on the left when a code action is available at your cursor. You can click
434+-- the icon or open the code action menu with `Ctrl + .` on Windows/Linux or
435+-- `Command + .` on macOS. For more information, see the [Lean 4 VSCode
436+-- extension
437+-- manual](https://github.com/leanprover/vscode-lean4/blob/master/vscode-lean4/manual/manual.md#code-actions).
438+
439+-- Some code actions can generate the explicit branches needed for pattern
440+-- matching. This is especially useful when working with `match` expressions,
441+-- or with tactics such as `cases` and `induction`, which we saw in previous
442+-- chapters.
