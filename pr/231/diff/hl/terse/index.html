431--- ## Hoare Triples, Informally
432-
433--- A *Hoare triple* is a claim about the state before and after
434--- executing a command:
435-
436---   {{P}} c {{Q}}
437-
438--- This means:
439-
440--- - If command `c` begins execution in a state satisfying
441---   assertion `P`,
442-
443--- - and if `c` eventually terminates in some final state,
444-
445--- - then that final state will satisfy the assertion `Q`.
446-
447--- Assertion `P` is called the *precondition* of the triple,
448--- and `Q` is the *postcondition*.
449-
450--- For example,
451-
452--- - The Hoare triple
453-
454---   {{X = 0}} X := X + 1 {{X = 1}}
455-
456--- states that command `X := X + 1` will transform a state in

460-

855+-- ### Assignment
856+
857+-- How can we complete this triple?
858+
859+--   {{ ??? }}  X := Y  {{ X = 1 }}
860+
861+-- One natural possibility is:
862+
863+--   {{ Y = 1 }}  X := Y  {{ X = 1 }}
864+
865+-- The precondition is just the postcondition, but with `X`
866+-- replaced by `Y`.
867+
868+-- How about this one?
869+
870+--   {{ ??? }}  X := X + Y  {{ X = 1 }}
871+
872+-- Replace `X` with `X + Y`:
873+
874+--   {{ X + Y = 1 }}  X := X + Y  {{ X = 1 }}
875+
876+-- This works because "equals 1" holding of `X` is guaranteed
877+-- by the property "equals 1" holding of whatever is being
878+-- assigned to `X`.
879+
880+-- In general, the postcondition could be some arbitrary
881+-- assertion `Q`, and the right-hand side of the assignment
882+-- could be some arbitrary arithmetic expression `a`:
883+
884+--   {{ ??? }}  X := a  {{ Q }}
885+
886+-- The precondition would then be `Q`, but with any occurrences
887+-- of `X` in it replaced by `a`.
888+
889+-- Let's introduce a notation for this idea of replacing
890+-- occurrences: Define `Q \[X ↦ a`] to mean "`Q` where `a` is
891+-- substituted in place of `X`".
892+
893+-- This yields the Hoare logic rule for assignment:
894+
895+--   {{ Q [X ↦ a] }}  X := a  {{ Q }}
896+
897+-- One way of reading this rule is: If you want statement
898+-- `X := a` to terminate in a state that satisfies assertion
899+-- `Q`, then it suffices to start in a state that also
900+-- satisfies `Q`, except where `a` is substituted for every
901+-- occurrence of `X`.
902+
903+-- Here are some valid instances of the assignment rule:
904+
905+--   {{ (X ≤ 5) [X ↦ X + 1] }}         (that is, X + 1 ≤ 5)
906+--     X := X + 1
907+--   {{ X ≤ 5 }}
908+
909+--   {{ (X = 3) [X ↦ 3] }}              (that is, 3 = 3)
910+--     X := 3

912+

914+--     X := 3
915+--   {{ 0 ≤ X ∧ X ≤ 5 }}

920+-- `Assertion.subst`.

923+-- arithmetic expression `a`, we want to derive another
924+-- proposition `P'` that is just the same as `P` except that
925+-- `P'` should mention `a` wherever `P` mentions `X`.
