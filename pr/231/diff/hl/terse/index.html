431--- ## Hoare Triples, Informally
432-
433--- A *Hoare triple* is a claim about the state before and after
434--- executing a command:
435-
436---   {{P}} c {{Q}}
437-
438--- This means:
439-
440--- - If command `c` begins execution in a state satisfying
441---   assertion `P`,
442-
443--- - and if `c` eventually terminates in some final state,
444-
445--- - then that final state will satisfy the assertion `Q`.
446-
447--- Assertion `P` is called the *precondition* of the triple,
448--- and `Q` is the *postcondition*.
449-
450--- For example,
451-
452--- - The Hoare triple
453-
454---   {{X = 0}} X := X + 1 {{X = 1}}
455-
456--- states that command `X := X + 1` will transform a state in
457--- which `X = 0` to a state in which `X = 1`.
458-
459--- - On the other hand,
460-
461---   ∀ m, {{X = m}} X := X + 1 {{X = m + 1}}
462-
463--- is a *proposition* stating that the Hoare triple
464--- `{{X = m}} X :=
465--- X + 1 {{X = m + 1}}` is valid for any choice
466--- of `m`. Note that `m` in the two assertions is a reference
467--- to the *Lean* variable `m`, which is bound outside the Hoare
468--- triple.

860+-- ### Assignment
861+
862+-- How can we complete this triple?
863+
864+--   {{ ??? }}  X := Y  {{ X = 1 }}
865+
866+-- One natural possibility is:
867+
868+--   {{ Y = 1 }}  X := Y  {{ X = 1 }}
869+
870+-- The precondition is just the postcondition, but with `X`
871+-- replaced by `Y`.
872+
873+-- How about this one?
874+
875+--   {{ ??? }}  X := X + Y  {{ X = 1 }}
876+
877+-- Replace `X` with `X + Y`:
878+
879+--   {{ X + Y = 1 }}  X := X + Y  {{ X = 1 }}
880+
881+-- This works because "equals 1" holding of `X` is guaranteed
882+-- by the property "equals 1" holding of whatever is being
883+-- assigned to `X`.

885+-- In general, the postcondition could be some arbitrary
886+-- assertion `Q`, and the right-hand side of the assignment
887+-- could be some arbitrary arithmetic expression `a`:
888+
889+--   {{ ??? }}  X := a  {{ Q }}

906+-- occurrence of `X`.
