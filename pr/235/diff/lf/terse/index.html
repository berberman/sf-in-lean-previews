55--- *Hoare Logic*: This short volume describes one of the
56--- primary methods for reasoning about *imperative* programs-
57--- programs with state and mutation, like C++, Java, C, and
58--- Assembly- in a pure logic like Lean's. This method, called
59--- *Hoare Logic*, is embeddable into Lean's type system and is
60--- a powerful tool for determining the correct behavior of
61--- imperative code. Since most of the code in the wild today is
62--- imperative, this technique is both well-established and
63--- popular among industry professionals who analyze and fortify
64--- the correctness of systems.
44+-- - *Hoare Logic* introduces imperative programs and Hoare
45+--   logic, a framework for stating and proving correctness
46+--   properties of programs with mutable state.
6547 
66--- *Type Systems*: Another tool for reasoning about the
67--- correctness of a program is a *type system*. You have
68--- interacted thoroughly with Lean's rich type system, which is
69--- one of the most complex in a modern programming language.
70--- Most languages have type systems that are far less complex,
71--- but which still provide incredibly useful guardrails against
72--- ill-behaved programs. In this volume you will explore how to
73--- read, analyze, and design type systems in a proof assistant.
