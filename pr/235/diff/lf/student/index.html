46--- *Hoare Logic*: This short volume describes one of the primary methods for
47--- reasoning about *imperative* programs- programs with state and mutation,
48--- like C++, Java, C, and Assembly- in a pure logic like Lean's. This method,
49--- called *Hoare Logic*, is embeddable into Lean's type system and is a
50--- powerful tool for determining the correct behavior of imperative code.
51--- Since most of the code in the wild today is imperative, this technique is
52--- both well-established and popular among industry professionals who analyze
53--- and fortify the correctness of systems.
43+-- - *Hoare Logic* introduces imperative programs and Hoare logic, a framework
44+--   for stating and proving correctness properties of programs with mutable
45+--   state.
5446 
55--- *Type Systems*: Another tool for reasoning about the correctness of a
56--- program is a *type system*. You have interacted thoroughly with Lean's rich
57--- type system, which is one of the most complex in a modern programming
58--- language. Most languages have type systems that are far less complex, but
59--- which still provide incredibly useful guardrails against ill-behaved
60--- programs. In this volume you will explore how to read, analyze, and design
61--- type systems in a proof assistant.
