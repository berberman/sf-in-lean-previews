53--- Our goal in this chapter is to develop the tools to work
54--- through some simple examples of *program verification* --
55--- i.e., to use the precise definition of Imp to prove formally
56--- that particular programs satisfy particular specifications
57--- of their behavior.
58-
59--- We'll develop a reasoning system called *Floyd-Hoare Logic*
60--- -- often shortened to just *Hoare Logic* -- in which each of
61--- the syntactic constructs of Imp is equipped with a generic
62--- "proof rule" that can be used to reason compositionally
63--- about the correctness of programs involving this construct.
64-
65--- Hoare Logic combines two beautiful ideas: a natural way of
66--- writing down *specifications* of programs, and a *structured
67--- proof technique* for proving that programs are correct with
68--- respect to such specifications -- where by "structured" we
69--- mean that the structure of proofs directly mirrors the
70--- structure of the programs that they are about.

431--- ## Hoare Triples, Informally
432-
433--- A *Hoare triple* is a claim about the state before and after
434--- executing a command:
435-
436---   {{P}} c {{Q}}
437-
438--- This means:
439-
440--- - If command `c` begins execution in a state satisfying
441---   assertion `P`,
442-
443--- - and if `c` eventually terminates in some final state,
444-
445--- - then that final state will satisfy the assertion `Q`.
446-
447--- Assertion `P` is called the *precondition* of the triple,
448--- and `Q` is the *postcondition*.
449-
450--- For example,
451-
452--- - The Hoare triple
453-
454---   {{X = 0}} X := X + 1 {{X = 1}}
455-
456--- states that command `X := X + 1` will transform a state in
457--- which `X = 0` to a state in which `X = 1`.
458-
459--- - On the other hand,
460-
461---   ∀ m, {{X = m}} X := X + 1 {{X = m + 1}}
462-
463--- is a *proposition* stating that the Hoare triple
464--- `{{X = m}} X :=
465--- X + 1 {{X = m + 1}}` is valid for any choice
466--- of `m`. Note that `m` in the two assertions is a reference
467--- to the *Lean* variable `m`, which is bound outside the Hoare
468--- triple.
