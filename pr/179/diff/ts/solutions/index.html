129+-- ## Proof-Carrying Typeclasses
130+
131+-- Notably, the above examples enforce no conditions on the data that they
132+-- carry, and we could provide any value that we would like for `HasOne.one`.
133+-- This could be misleading, for instance if we had instead defined an
134+-- instance
135+
136+sf_experiment
137+  instance : HasOne Nat where
138+    one := 2
139+
140+-- we might have some counterintuitive proofs based on the name leading us to
141+-- believe the class contained the element `1`. In most languages that support
142+-- typeclasses it is not possible to enforce a notion of "lawfulness" as part
143+-- of the typeclass, and it falls to the author to ensure that any desired
144+-- invariants are satisfied.

146+-- As an example, suppose that we wanted to express the idea that a type has
147+-- at least two distinct elements. A first attempt might be
