1097+--  We've now talked about many of Lean's most fundamental tactics. We'll

1103+--  Here are the tactics we've seen so far.
1104+--
1105+--  Managing goals and hypotheses:
1106+--
1107+--  - `intro h`: move an assumption/quantified variable from the goal into
1108+--    the local context
1109+--
1110+--  - `apply thm`: use a theorem, hypothesis, or constructor whose
1111+--    conclusion matches the goal; its premises become new goals
1112+--
1113+--  - `apply thm at h`: use a theorem on a hypothesis in the context,
1114+--    replacing `h` by the resulting fact (forward reasoning)
1115+--
1116+--  - `specialize h ...`: instantiate quantified variables in a hypothesis,
1117+--    modifying `h` in place
1118+--
1119+--  - `replace h := ...`: replace a hypothesis with a newly proved fact
1120+--
1121+--  - `have h : P := ...`: prove a local fact `P` and add it to the context
1122+--    with the name `h`
1123+--
1124+--  - `contradiction`: close the current goal when the context contains
1125+--    contradictory assumptions
1126+--
1127+--  Equality, rewriting, and unfolding:
1128+--
1129+--  - `rfl`: close an equality that holds by reflexivity (possibly after
1130+--    computation)
1131+--
1132+--  - `rw [h]`: rewrite the goal using an equality hypothesis or theorem
1133+--
1134+--  - `rw [d]`: unfold a definition in the goal
1135+--
1136+--  - `rw [h] at h'`: rewrite a hypothesis using an equality hypothesis or
1137+--    theorem
1138+--
1139+--  - `rw [d] at h'`: unfold a definition in a hypothesis
1140+--
1141+--  - `symm`: reverse an equality goal, changing `t = u` to `u = t`
1142+--
1143+--  - `symm at h`: reverse an equality hypothesis
1144+--
1145+--  - `calc`: prove a goal about equality or another transitive relation by
1146+--    giving a sequence of intermediate steps
1147+--
1148+--  - `congr`: use congruence to reduce an equality between expressions
1149+--    with the same outer form; for example, a goal `f x = f y` may be
1150+--    reduced to `x = y`
1151+--
1152+--  - `injection h with ...`: use injectivity of constructors to extract

1154+--
1155+--  - `injections`: repeatedly use constructor injectivity on suitable
1156+--    equalities in the context
1157+--
1158+--  Case analysis:
1159+--

1161+--    inductively defined value
1162+--
