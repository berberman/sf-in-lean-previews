670+--  ## Review
671+
672+--  Here are the tactics we've seen so far.
673+--
674+--  Managing goals and hypotheses:
675+--
676+--  - `intro h`: move an assumption/quantified variable from
677+--    the goal into the local context
678+--
679+--  - `apply thm`: use a theorem, hypothesis, or constructor
680+--    whose conclusion matches the goal; its premises become
681+--    new goals
682+--
683+--  - `apply thm at h`: use a theorem on a hypothesis in the
684+--    context, replacing `h` by the resulting fact (forward
685+--    reasoning)
686+--
687+--  - `specialize h ...`: instantiate quantified variables
688+--    in a hypothesis, modifying `h` in place
689+--
690+--  - `replace h := ...`: replace a hypothesis with a newly
691+--    proved fact
692+--
693+--  - `have h : P := ...`: prove a local fact `P` and add it
694+--    to the context with the name `h`
695+--
696+--  - `contradiction`: close the current goal when the
697+--    context contains contradictory assumptions
698+--
699+--  Equality, rewriting, and unfolding:
700+--
701+--  - `rfl`: close an equality that holds by reflexivity
702+--    (possibly after computation)
703+--
704+--  - `rw [h]`: rewrite the goal using an equality
705+--    hypothesis or theorem
706+--
707+--  - `rw [d]`: unfold a definition in the goal
708+--
709+--  - `rw [h] at h'`: rewrite a hypothesis using an equality
710+--    hypothesis or theorem
711+--
712+--  - `rw [d] at h'`: unfold a definition in a hypothesis
713+--
714+--  - `symm`: reverse an equality goal, changing `t = u` to
715+--    `u = t`
716+--
717+--  - `symm at h`: reverse an equality hypothesis
718+--
719+--  - `calc`: prove a goal about equality or another
720+--    transitive relation by giving a sequence of
721+--    intermediate steps
722+--
723+--  - `congr`: use congruence to reduce an equality between
724+--    expressions with the same outer form; for example, a
725+--    goal `f x = f y` may be reduced to `x = y`
726+--
727+--  - `injection h with ...`: use injectivity of
728+--    constructors to extract equalities from equations
729+--    between constructor applications
730+--
731+--  - `injections`: repeatedly use constructor injectivity
732+--    on suitable equalities in the context
733+--
734+--  Case analysis:
735+--
736+--  - `cases x`: reason separately about the possible
737+--    constructors of an inductively defined value
738+--
739+--  - `cases h : e`: perform case analysis on an expression
740+--    `e` and add an equation named `h` recording the result
741+--    of the case analysis
742+--
743+--  Induction:
744+--
745+--  - `induction x`: prove the goal by induction on an
746+--    inductively defined value
747+--
748+--  - `induction x generalizing y`: induction on `x` while
749+--    generalizing the listed local variables, giving a more
750+--    general induction hypothesis
