1238+--  ## Review
1239+
1240+--  We've now talked about many of Lean's most fundamental tactics. We'll
1241+--  introduce a few more in the coming chapters, and later on we'll see

1246+--  Here are the tactics we've seen so far.
1247+--
1248+--  Managing goals and hypotheses:
1249+--
1250+--  - `intro h`: move an assumption/quantified variable from the goal into
1251+--    the local context
1252+--
1253+--  - `apply thm`: use a theorem, hypothesis, or constructor whose
1254+--    conclusion matches the goal; its premises become new goals
1255+--
1256+--  - `apply thm at h`: use a theorem on a hypothesis in the context,
1257+--    replacing `h` by the resulting fact (forward reasoning)
1258+--
1259+--  - `specialize h ...`: instantiate quantified variables in a hypothesis,
1260+--    modifying `h` in place
1261+--
1262+--  - `replace h := ...`: replace a hypothesis with a newly proved fact
1263+--
1264+--  - `have h : P := ...`: prove a local fact `P` and add it to the context
1265+--    with the name `h`
1266+--
1267+--  - `contradiction`: close the current goal when the context contains
1268+--    contradictory assumptions
1269+--
1270+--  Equality, rewriting, and unfolding:
1271+--
1272+--  - `rfl`: close an equality that holds by reflexivity (possibly after
1273+--    computation)
1274+--
1275+--  - `rw [h]`: rewrite the goal using an equality hypothesis or theorem
1276+--
1277+--  - `rw [d]`: unfold a definition in the goal
1278+--
1279+--  - `rw [h] at h'`: rewrite a hypothesis using an equality hypothesis or
1280+--    theorem
1281+--
1282+--  - `rw [d] at h'`: unfold a definition in a hypothesis
1283+--
1284+--  - `symm`: reverse an equality goal, changing `t = u` to `u = t`
1285+--
1286+--  - `symm at h`: reverse an equality hypothesis
1287+--
1288+--  - `calc`: prove a goal about equality or another transitive relation by
1289+--    giving a sequence of intermediate steps
1290+--
1291+--  - `congr`: use congruence to reduce an equality between expressions
1292+--    with the same outer form; for example, a goal `f x = f y` may be
1293+--    reduced to `x = y`
1294+--
1295+--  - `injection h with ...`: use injectivity of constructors to extract
1296+--    equalities from equations between constructor applications
1297+--
1298+--  - `injections`: repeatedly use constructor injectivity on suitable
1299+--    equalities in the context
1300+--
1301+--  Case analysis:
1302+--
