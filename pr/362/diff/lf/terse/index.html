720+--  ### Splitting with Equations
721+
722+--  When using `cases`, we can specify to Lean that it
723+--  should remember an equality between a compound
724+--  expression and what we are decomposing it into, using
725+--  `cases h : ...` syntax. This information can actually be
726+--  critical, and, if we leave it out, we might lack
727+--  information we need to complete a proof.

729+def keepIf {α : Type} (test : α → Bool) (x : α) : Option α :=
730+  if test x then some x else none

733+--  we can use it.

735+theorem keepIf_some {α : Type} (test : α → Bool) (x y : α)
736+    (h : keepIf test x = some y) :

741+  -- above, except that the context contains an extra equality
742+  -- assumption, which is exactly what we need to make progress.
743+  · rw [hTest] at h
744+    contradiction
