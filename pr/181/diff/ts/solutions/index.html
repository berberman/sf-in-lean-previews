284added-- The substitution lemma can be viewed as a kind of "commutation property."
285added-- Intuitively, it says that substitution and typing can be done in either
286added-- order: we can either assign types to the terms `t` and `v` separately
287added-- (under suitable contexts) and then combine them using substitution, or we
288added-- can substitute first and then assign a type to ` `x:=v` t`; the result is
289added-- the same either way.
290added
291added-- *Proof*: We show, by induction on `t`, that for all `T` and `Γ`, if
292added-- `x ↦ U; Γ ⊢ t ⦂ T` and `⊢ v ⦂ U`, then `Γ ⊢ [x:=v]t ⦂ T`.
293added
294added-- - If `t` is a variable there are two cases to consider, depending on whether
295added-- `t` is `x` or some other variable.
296added
297added-- - If `t = x`, then from the fact that `x ↦ U; Γ ⊢ x ⦂ T` we conclude that
298added-- `U = T`. We must show that `[x:=v]x = v` has type `T` under `Γ`, given the
299added-- assumption that `v` has type `U = T` under the empty context. This follows
300added-- from the weakening lemma.
301added
302added-- - If `t` is some variable `y` that is not equal to `x`, then we need only
303added-- note that `y` has the same type under `x ↦ U; Γ` as under `Γ`.
304added
305added-- - If `t` is an abstraction `λy:S. t₀`, then `T = S→T₁` and the IH tells us,
306added-- for all `Γ'` and `T₀`, that if `x ↦ U; Γ' ⊢ t₀ ⦂ T₀`, then
307added-- `Γ' ⊢ [x:=v]t₀ ⦂ T₀`. Moreover, by inspecting the typing rules we see it
308added-- must be the case that `y ↦ S; x ↦ U; Γ ⊢ t₀ ⦂ T₁`.
309added
310added-- The substitution in the conclusion behaves differently depending on whether
311added-- `x` and `y` are the same variable.
312added
313added-- First, suppose `x = y`. Then, by the definition of substitution,
314added-- `[x:=v]t = t`, so we just need to show `Γ ⊢ t ⦂ T`. Using `HasType.abs`, we
315added-- need to show that `y ↦ S; Γ ⊢ t₀ ⦂ T₁`. But we know
316added-- `y ↦ S; x ↦ U; Γ ⊢ t₀ ⦂ T₁`, and the claim follows since `x = y`.
317added
318added-- Second, suppose `x <> y`. Again, using `HasType.abs`, we need to show that
319added-- `y ↦ S; Γ ⊢ [x:=v]t₀ ⦂ T₁`. Since `x <> y`, we have
320added-- `y ↦ S; x ↦ U; Γ = x ↦ U; y ↦ S; Γ`. So we have
321added-- `x ↦ U; y ↦ S; Γ ⊢ t₀ ⦂ T₁`. Then, the the IH applies (taking
322added-- `Γ' = y ↦ S; Γ`), giving us `y ↦ S; Γ ⊢ [x:=v]t₀ ⦂ T₁`, as required.
323added
324added-- - If `t` is an application `t₁ t₂`, the result follows straightforwardly from
325added-- the definition of substitution and the induction hypotheses.
326added
327added-- - The remaining cases are similar to the application case.
328added
329added-- One technical subtlety in the statement of the above lemma is that we
330added-- assume `v` has type `U` in the *empty* context — in other words, we assume
331added-- `v` is closed. (Since we are using a simple definition of substition that
332added-- is not capture-avoiding, it doesn't make sense to substitute non-closed
333added-- terms into other terms. Fortunately, closed terms are all we need!)

511added-- Another standard technical lemma associated with typed languages is
512added-- *context invariance*. It states that typing is preserved under "inessential
513added-- changes" to the context `Γ` — in particular, changes that do not affect any
514added-- of the free variables of the term. In this section, we establish this
515added-- property for our system, introducing some other standard terminology on the
516added-- way.
517added
518added-- First, we need to define the *free variables* in a term — i.e., variables
519added-- that are used in the term in positions that are *not* in the scope of an
520added-- enclosing function abstraction binding a variable of the same name.
521added
522added-- More technically, a variable `x` *appears free in* a term *t* if `t`
523added-- contains some occurrence of `x` that is not under an abstraction labeled
524added-- `x`. For example:
525added
526added-- - `y` appears free, but `x` does not, in `λx:T→U. x y`
527added-- - both `x` and `y` appear free in `(λx:T→U. x y) x`
528added-- - no variables appear free in `λx:T→U. λy:T. x y`
529added
530added-- We write this `x ∈ᶠ t`, reading the relation as "`x` is one of the free
531added-- variables of `t`". Formally:

540added | app2 (t₁ t₂ : Tm) (h : x ∈ᶠ t₂) : x ∈ᶠ <{ ~t₁ ~t₂ }>

671added-- *Proof*: By induction on the derivation of `Γ ⊢ t ⦂ T`.
672added
673added-- - If the last rule in the derivation was `HasType.var`, then `t = x` and
674added-- `Γ x = T`. By assumption, `Γ' x = T` as well, and hence `Γ' ⊢ t ⦂ T` by
675added-- `HasType.var`.
676added
677added-- - If the last rule was `HasType.abs`, then `t = λy:T₂. t₁`, with
678added-- `T = T₂ → T₁` and `y ↦ T₂; Γ ⊢ t₁ ⦂ T₁`. The induction hypothesis states
679added-- that for any context `Γ''`, if `y ↦ T₂; Γ` and `Γ''` assign the same types
680added-- to all the free variables in `t₁`, then `t₁` has type `T₁` under `Γ''`. Let
681added-- `Γ'` be a context which agrees with `Γ` on the free variables in `t`; we
682added-- must show `Γ' ⊢ λy:T₂. t₁ ⦂ T₂ → T₁`.
683added
684added-- By `HasType.abs`, it suffices to show that `y ↦ T₂; Γ' ⊢ t₁ ⦂ T₁`. By the
685added-- IH (setting `Γ'' = y ↦ T₂;Γ'`), it suffices to show that `y ↦ T₂;Γ` and
686added-- `y ↦ T₂;Γ'` agree on all the variables that appear free in `t₁`.
687added
688added-- Any variable occurring free in `t₁` must be either `y` or some other
689added-- variable. `y ↦ T₂; Γ` and `y ↦ T₂; Γ'` clearly agree on `y`. Otherwise,
690added-- note that any variable other than `y` that occurs free in `t₁` also occurs
691added-- free in `t = λy:T₂. t₁`, and by assumption `Γ` and `Γ'` agree on all such
692added-- variables; hence so do `y ↦ T₂; Γ` and `y ↦ T₂; Γ'`.
693added
694added-- - If the last rule was `HasType.app`, then `t = t₁ t₂`, with
695added-- `Γ ⊢ t₁ ⦂ T₂ → T` and `Γ ⊢ t₂ ⦂ T₂`. One induction hypothesis states that
696added-- for all contexts `Γ'`, if `Γ'` agrees with `Γ` on the free variables in
697added-- `t₁`, then `t₁` has type `T₂ → T` under `Γ'`; there is a similar IH for
698added-- `t₂`. We must show that `t₁ t₂` also has type `T` under `Γ'`, given the
699added-- assumption that `Γ'` agrees with `Γ` on all the free variables in `t₁ t₂`.
700added-- By `HasType.app`, it suffices to show that `t₁` and `t₂` each have the same
701added-- type under `Γ'` as under `Γ`. But all free variables in `t₁` are also free
702added-- in `t₁ t₂`, and similarly for `t₂`; hence the desired result follows from
703added-- the induction hypotheses.
