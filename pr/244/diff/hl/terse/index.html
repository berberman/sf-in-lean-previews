250+/-- In Lean, "inversion" on `leq : f n ≤ 0`, where `f : Nat → Nat`,
251+  requires `generalizing e : f n = m`, since Lean does not perform
252+  the dependent case analysis automatically. `cases leq` will fail here.
253+  We want to keep the style of reasoning familiar to PL:
254+  "I know `h`; what must have been true for `h` to be true?"
255+  The technicality of needing to generalize hinders teaching and learning
256+  this style of reasoning for audiences new to proof assistants and logic.
257+  To solve this, we introduce and use the `inversion` tactic,
258+  which automatically generalizes varaibles, performs case analysis,
259+  and eliminates impossible subcases. -/
