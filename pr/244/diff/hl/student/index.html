22+/- n Lean, "Inversion" on `h: f n ≤ 0`, where `f : nat -> nat`,
23+requires `generalizing e : f n = m`, since Lean does not perform the
24+dependent case analysis automatically. `cases h` will fail here. We
25+want to keep the style of reasoning familiar to PL: "I know h, what
26+must have been true for h to be true." We feel that the technicality
27+of needing to generalize hinders teaching and learning this style of
28+reasoning for new audiences to proof assistants and logic. To solve
29+this, we introduce and use the `inversion` tactic, which automatically
30+generalizes varaibles, performs case analysis, and eliminates
31+impossible subcases. -/
