1801+-- Now that we have learned the basic features of Lean 4, let's close the
1802+-- chapter with an exercise that brings them together.
1803+
1804+-- One fascinating aspect of using a theorem prover like Lean is that we can
1805+-- do more than implement a system — we can also state precisely what we
1806+-- expect the system to behave and prove that our implementation satisfies
1807+-- those expectations.
1808+
1809+-- In this exercise, we will model part of an airport database. The airport
1810+-- stores one database entry for each traveler. An entry records where the
1811+-- traveler is in the airport process, together with information about their
1812+-- current bag.
1813+
1814+-- We will implement several operations on these entries and prove general
1815+-- properties about their behavior.
1816+
1817+namespace Airport
1818+
1819+-- For simplicity, we assume that a bag either contains a battery, which
1820+-- causes it to fail inspection, or contains only ordinary items:
1821+
1822+inductive BagContent : Type where
1823+  | battery
1824+  | ordinary
1825+
1826+-- The screening status records whether the bag has not yet been inspected,
1827+-- has been cleared, or has been blocked:
1828+
1829+inductive ScreeningStatus : Type where
1830+  | notScreened
1831+  | cleared
1832+  | blocked

1834+-- A traveler can be in one of three stages:
1835+
