256+--  If you are **using this book as part of a class**, your instructor will

270+--  #### Downloading and building the book from Git, for self study
271+
272+--  If you are **going through Software Foundations on your own**, you can
273+--  get the most up-to-date version from the
274+--  [SF-in-Lean](https://github.com/plclub/sf-in-lean) GitHub repository.
275+--  Clone that repository and then build it by typing `make` from the root
276+--  directory. This will construct various versions of the book.
277+
278+--  Assuming you want to start from the beginning, we recommend typing
279+--  `make lf-student` instead. This builds the *Logical Foundations* volume
280+--  in its student form (full prose, with solutions elided) and writes two
281+--  things to `_out/lf/student/`:
282+
283+--  - `html/`, an HTML-formatted version of the whole book; and
284+
285+--  - `lean/`, a standalone Lean project holding the same chapters as
286+--    `.lean` files, with solutions to exercises omitted.
287+
288+--  Use `make student` instead if you also want *Type Systems* (`ts`) and
289+--  *Hoare Logic* (`hl`). The first build compiles the whole dependency
290+--  tree and takes a while; later builds are incremental.
291+
292+--  Now you can open the generated Lean project as its own folder — not as
293+--  a file inside your clone:
294+
295+--    code _out/lf/student/lean
296+
297+--  or
298+
299+--    cd _out/lf/student/lean
300+--    code .
301+
302+--  You can also use File → Open Folder.
303+
304+--  Treat this as a scratch copy: **every `make` regenerates it from the
305+--  Verso sources, overwriting whatever is there.** Work on your proofs
306+--  here, but keep anything you want to survive somewhere else.

308+--  If you would like to read the book HTML, start a local HTTP server and
