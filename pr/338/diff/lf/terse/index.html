314+--  #### Downloading and building the book from Git, for self study
315+
316+--  If you are **reading Software Foundations on your own**,
317+--  you can get the most up-to-date version from the
318+--  [SF-in-Lean](https://github.com/plclub/sf-in-lean)
319+--  GitHub repository. Clone that repository and then build
320+--  it by typing `make lf-student` from the root directory.
321+--  Doing so will construct the student version (full prose,
322+--  with solutions elided) of the *Logical Foundations*
323+--  book.
324+
325+--  Building the book requires that you have Lean installed.
326+--  If you do not, follow the instructions
327+--  [here](https://lean-lang.org/install/manual/) to install
328+--  the Lean toolchain manager `elan` which will then manage
329+--  your Lean installation. Alternatively, once you have
330+--  added the Lean 4 extension to VS Code, you can open a
331+--  Lean file in the repository (for example, `LF.lean` from
332+--  the top level directory) and it will install `elan` and
333+--  Lean automatically. Both installation methods have the
334+--  same effect, putting the Lean toolchain in the same
335+--  place on your filesystem.
336+
337+--  With Lean installed, `make lf-student` writes two things
338+--  to `_out/lf/student/`:
339+
340+--  - `html/`, an HTML-formatted version of the whole book;
341+--    and
342+
343+--  - `lean/`, a standalone Lean project holding the same
344+--    chapters as `.lean` files, with solutions to exercises
345+--    omitted.
346+
347+--  Use `make student` instead if you also want *Type
348+--  Systems* (`ts`) and *Hoare Logic* (`hl`). The first
349+--  build compiles the whole dependency tree and takes a
350+--  while; later builds are incremental.
351+
352+--  Now you can open the generated Lean project as its own
353+--  folder — not as a file inside your clone:
354+
355+--    code _out/lf/student/lean
