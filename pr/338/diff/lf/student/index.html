262+--  #### Downloading and building the book from Git, for self study
263+
264+--  If you are **reading Software Foundations on your own**, you can get
265+--  the most up-to-date version from the
266+--  [SF-in-Lean](https://github.com/plclub/sf-in-lean) GitHub repository.
267+--  Clone that repository and then build it by typing `make` from the root
268+--  directory. This will construct various versions of the book.
269+
270+--  Assuming you want to start from the beginning, we recommend typing
271+--  `make lf-student` instead. This builds the *Logical Foundations* volume
272+--  in its student form (full prose, with solutions elided) and writes two
273+--  things to `_out/lf/student/`:
274+
275+--  - `html/`, an HTML-formatted version of the whole book; and
276+
277+--  - `lean/`, a standalone Lean project holding the same chapters as
278+--    `.lean` files, with solutions to exercises omitted.
279+
280+--  Use `make student` instead if you also want *Type Systems* (`ts`) and
281+--  *Hoare Logic* (`hl`). The first build compiles the whole dependency
282+--  tree and takes a while; later builds are incremental.
283+
284+--  Now you can open the generated Lean project as its own folder — not as
285+--  a file inside your clone:
286+
287+--    code _out/lf/student/lean
288+
289+--  or
290+
291+--    cd _out/lf/student/lean
292+--    code .

294+--  You can also use File → Open Folder.
