264+--  If you are **reading Software Foundations on your own**, you can get

271+--  Building the book requires that you have Lean installed. If you do not,
272+--  follow the instructions [here](https://lean-lang.org/install/manual/)

274+--  your Lean installation. Alternatively, once you have added the Lean 4
275+--  extension to VS Code, you can open a Lean file in the repository (for
276+--  example, `LF.lean` from the top level directory) and it will install
277+--  `elan` and Lean automatically. Both installation methods have the same
278+--  effect, putting the Lean toolchain in the same place on your
