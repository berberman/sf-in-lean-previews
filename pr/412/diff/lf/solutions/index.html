346+--
347+--  The tactic simplifies the target (the goal and/or one or more
348+--  hypotheses) by repeatedly rewriting it using a set of lemmas. At each
349+--  step it tries every lemmas in its available set the way `first` would,
350+--  applies whichever one matches via `rw`, and `repeat`s until no lemma

461+--      Should we add something like the following, to explain conditional
462+--      rewrites?
463+--
464+--      Recall from Tactics that rewriting with a theorem
465+--      `h₁ -> h₂ -> a = b` uses `a = b` and leaves `h₁` and `h₂` as new
466+--      subgoals. We can include such theorems in `simp`'s available set,
467+--      too, but it handles the premises differently: it tries to discharge
468+--      `h₁`, `h₂` too, recursively, using `simp` again (by default), and
469+--      only fires the rewrite if it succeeds. If it can't discharge a
470+--      premise, it just doesn't use that lemma.
471+--
472+--      Claude tested three variants of this against the real toolchain
473+--      (`lake env lean`). `double_injective` from `Tactics` doesn't
474+--      actually work here: its conclusion is the bare variable `n = m`,
475+--      which isn't a usable rewrite pattern (simp lemmas need a real
476+--      compound term on the left), so `simp [double_injective]` fails
477+--      outright with "simp made no progress" before it ever gets anywhere
478+--      near the `n.double = m.double` premise.
479+--
480+--      A conditional lemma that does have a proper compound left-hand
481+--      side, like `Nat.sub_add_cancel : n ≤ m -> m - n + n = m`, tells a
482+--      cleaner three-part story. With `hle : n ≤ m` in context:
483+--
484+--      `example (n m : Nat) (hle : n ≤ m) : m - n + n = m := by
485+--        simp [Nat.sub_add_cancel]        -- fails: "simp made no progress"
486+--
487+--      example (n m : Nat) (hle : n ≤ m) : m - n + n = m := by
488+--        simp [Nat.sub_add_cancel, hle]   -- succeeds
489+--
490+--      example (n m : Nat) (hle : n ≤ m) : m - n + n = m := by
491+--        simp_all [Nat.sub_add_cancel]    -- succeeds, without naming hle`
492+--
493+--      The first case shows the discharge step only consults the active
494+--      simp set (default set plus whatever's explicitly listed) -- not
495+--      arbitrary context hypotheses -- so `hle` sitting right there
496+--      doesn't help; simp just skips the lemma, exactly the "no error, no
497+--      leftover subgoal" behavior claimed above. The second shows
498+--      discharge working once `hle` is added to the set. The third
499+--      previews `simp_all` (introduced a bit further down this chapter):
