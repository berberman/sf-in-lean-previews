310+--  powerful tools in the language, and it is used heavily in real Lean

312+--
313+--  The tactic simplifies the target (the goal and/or one or more
314+--  hypotheses) by repeatedly rewriting it using a set of lemmas. At each
315+--  step it tries every lemma in its available set the way `first` would,
316+--  applies whichever one matches via `rw`, and `repeat`s until no lemma
317+--  applies anywhere. Like `repeat`, it fails outright if it never manages
318+--  to apply a rewrite ("simp made no progress"), rather than succeeding as
319+--  a no-op the way `try` `simp` would.
